# Лабораторная работа №6
## Строки
### Цель:
Изучение символьных и строковых переменных и способов их обработки в языке Си.

### Постановка задачи.
Задана строка, состоящая из символов. Символы объединяются в слова. Слова друг от друга отделяются  одним или несколькими пробелами. В конце текста ставится точка. Текст содержит не  более 255 символов. Выполнить ввод строки, используя функцию Gets(s)  и обработку строки в соответствии со своим вариантом.

### Задание. Вариант 21.
Программа содержится в файле [code.cpp](code.cpp).\
Также к ней составлена блок-схема через специальное приложение drawio, содержимое которой предоставлено в файле [blocks.drawio](blocks.drawio).

### Алгоритм решения

Для решения задачи необходимо выполнить следующие действия:

- Подключить библиотеки для ввода и вывода данных, работы со строками и настройки локали.
- В основной функции `main()` установить русскую локаль с помощью `setlocale(LC_ALL, "Russian")`.
- Объявить символьный массив `s` размером 256 элементов для хранения исходной строки.
- Объявить символьный массив `result` размером 256 элементов для хранения обработанной строки.
- Выполнить ввод исходной строки с помощью функции `cin.getline(s, 256)`.
- Объявить и обнулить переменную `i`, предназначенную для перемещения по символам исходной строки.
- Объявить переменную `j` для определения позиции записи символов в результирующий массив.
- Организовать цикл `while`, который выполняется до обнаружения точки или конца строки.
- С помощью вложенного цикла `while` пропускать один или несколько пробелов между словами.
- Сохранить начальную позицию текущего слова в переменной `start`.
- С помощью цикла `while` определить конец текущего слова, перемещаясь по символам до пробела, точки или конца строки.
- Вычислить длину текущего слова и сохранить её в переменной `len`.
- Объявить логическую переменную `isIdentifier` и присвоить ей значение `true`.
- Проверить первый символ слова. Он должен быть латинской буквой или символом подчёркивания `_`.
- Если первый символ не соответствует правилам идентификатора, присвоить переменной `isIdentifier` значение `false`.
- С помощью цикла `for` проверить остальные символы текущего слова.
- Убедиться, что каждый последующий символ является латинской буквой, цифрой или символом подчёркивания `_`.
- Если обнаружен недопустимый символ, присвоить переменной `isIdentifier` значение `false` и завершить проверку текущего слова с помощью `break`.
- Если слово является идентификатором и его длина больше нуля, скопировать его в результирующий массив.
- Перед добавлением очередного слова проверить, содержит ли результирующий массив предыдущие слова. Если содержит, добавить пробел.
- С помощью цикла `for` последовательно скопировать символы текущего слова в массив `result`.
- После завершения обработки строки добавить в результирующий массив точку и нулевой символ `'\0'`.
- Вывести обработанную строку на экран.
- Завершить выполнение программы.

### Описание программы

Программа предназначена для удаления из заданной строки всех слов, которые не являются допустимыми идентификаторами языка C++.

В начале программы подключаются необходимые библиотеки:

```
#include <iostream>
#include <clocale>
```

Библиотека `iostream` используется для ввода и вывода данных, `clocale` — для настройки локали.

Далее с помощью директивы `using namespace std` подключается стандартное пространство имён.

В основной функции `main()` устанавливается русская локаль:

```
setlocale(LC_ALL, "Russian");
```

Затем объявляются два символьных массива:

```
char s[256];
char result[256];
```

Массив `s` предназначен для хранения исходной строки, а `result` — для записи слов, прошедших проверку.

Для ввода исходного текста используется функция:

```
cin.getline(s, 256);
```

После этого объявляются две переменные:

```
int i = 0;
int j = 0;
```

Переменная `i` используется для перемещения по исходной строке, а `j` определяет текущую позицию записи в результирующем массиве.

Для обработки строки используется цикл `while`:

```
while (s[i] != '.' && s[i] != '\0')
```

Цикл выполняется до тех пор, пока не встретится точка или символ конца строки.

Внутри цикла сначала пропускаются пробелы между словами:

```
while (s[i] == ' ') {
    i++;
}
```

Далее сохраняется начальная позиция текущего слова:

```
int start = i;
```

С помощью следующего цикла `while` определяется конец слова:

```
while (s[i] != ' ' && s[i] != '.' && s[i] != '\0') {
    i++;
}
```

Переменная `i` увеличивается до тех пор, пока программа не встретит пробел, точку или конец строки.

После определения границ слова вычисляется его длина:

```
int len = i - start;
```

Для проверки слова на соответствие правилам идентификатора используется логическая переменная:

```
bool isIdentifier = true;
```

Изначально предполагается, что слово является идентификатором.

Сначала проверяется первый символ слова:

```
if (!((s[start] >= 'a' && s[start] <= 'z') ||
      (s[start] >= 'A' && s[start] <= 'Z') ||
      s[start] == '_')) {
    isIdentifier = false;
}
```

Согласно правилам языка C++, идентификатор должен начинаться с латинской буквы или символа подчёркивания `_`.

Если первый символ не соответствует этим требованиям, слово признаётся недопустимым.

Далее с помощью цикла `for` проверяются остальные символы слова:

```
for (int k = 1; k < len; k++) {
    if (!((s[start + k] >= 'a' && s[start + k] <= 'z') ||
          (s[start + k] >= 'A' && s[start + k] <= 'Z') ||
          (s[start + k] >= '0' && s[start + k] <= '9') ||
          s[start + k] == '_')) {

        isIdentifier = false;
        break;
    }
}
```

В отличие от первого символа, остальные символы идентификатора могут содержать латинские буквы, цифры и символ подчёркивания.

Если обнаруживается недопустимый символ, переменной `isIdentifier` присваивается значение `false`, а оператор `break` завершает текущую проверку.

После проверки слова выполняется условие:

```
if (isIdentifier && len > 0)
```

Если слово является допустимым идентификатором, оно добавляется в результирующий массив.

Перед копированием слова проверяется, есть ли уже записанные символы в массиве `result`:

```
if (j > 0) {
    result[j] = ' ';
    j++;
}
```

Это необходимо для разделения сохранённых слов одним пробелом.

Затем с помощью цикла `for` выполняется копирование символов текущего слова:

```
for (int k = 0; k < len; k++) {
    result[j] = s[start + k];
    j++;
}
```

Таким образом, в результирующий массив попадают только слова, соответствующие правилам идентификаторов.

После завершения обработки исходной строки в результирующий массив добавляются точка и нулевой символ:

```
result[j] = '.';
result[j + 1] = '\0';
```

Символ `'\0'` обозначает конец символьной строки и необходим для её корректного вывода.

В завершение программа выводит полученную строку:

```
cout << "Result: " << result << endl;
```

Таким образом, программа последовательно проверяет каждое слово исходного текста и формирует новую строку, содержащую только допустимые идентификаторы.

### Результат работы

В результате выполнения программы на экран выводится обработанная строка, из которой удалены все слова, не являющиеся идентификаторами языка C++.

В качестве исходных данных используется следующая строка:

```
hello 123 world test_1 2abc my-name _value.
```

Рассмотрим проверку отдельных слов:

- `hello` — является идентификатором, поскольку состоит из латинских букв.
- `123` — не является идентификатором, поскольку начинается с цифры.
- `world` — является идентификатором.
- `test_1` — является идентификатором, поскольку содержит буквы, цифру и символ подчёркивания.
- `2abc` — не является идентификатором, поскольку начинается с цифры.
- `my-name` — не является идентификатором, поскольку содержит недопустимый символ `-`.
- `_value` — является идентификатором, поскольку начинается с символа подчёркивания.

После обработки остаются только допустимые идентификаторы.

Пример вывода:

```
Enter a string: hello 123 world test_1 2abc my-name _value.
Result: hello world test_1 _value.
```
