# Лабораторная работа №3
## Вычисление функций с использованием их разложения в степенной ряд
### Цель:
Практика в организации итерационных и арифметических циклов.

### Постановка задачи.
Для х изменяющегося от a до b с шагом (b - a) / k, где (k = 10), вычислить функцию f(x), используя ее разложение в степенной ряд в двух случаях:
а) для заданного n;
б) для заданной точности e (e = 0.0001).
Для сравнения найти точное значение функции.

### Задание. Вариант 21.
Программа содержится в файле [code.cpp](code.cpp).\
Также к ней составлена блок-схема через специальное приложение drawio, содержимое которой предоставлено в файле [blocks.drawio](blocks.drawio).

### Алгоритм решения

Для решения задачи необходимо выполнить следующие действия:

- Подключить библиотеки для ввода и вывода данных, настройки локали и работы с математическими функциями.
- В основной функции `main()` установить русскую локаль с помощью `setlocale(LC_ALL, "Russian")`.
- Задать границы интервала (a = 0.1) и (b = 1.0), количество шагов (k = 10), количество членов ряда (n = 40) и точность вычислений (e = 0.0001).
- Вычислить шаг изменения аргумента (h = (b - a) / k).
- С помощью внешнего цикла `for` перебрать значения аргумента (x) от (a) до (b) включительно.
- Для каждого значения (x) вычислить сумму степенного ряда с фиксированным количеством членов (n = 40).
- Для вычисления суммы использовать внутренний цикл `for`, последовательно добавляя очередные члены ряда к переменной `sn`.
- Вычислить сумму степенного ряда с заданной точностью (e = 0.0001), используя цикл `while`.
- На каждой итерации цикла `while` проверять абсолютное значение текущего члена ряда с помощью функции `fabs()`. Если оно не меньше заданной точности, добавить его к сумме `se` и вычислить следующий член ряда.
- С помощью функции `atan()` вычислить точное значение арктангенса для текущего аргумента (x).
- Вывести на экран текущее значение аргумента, сумму ряда с фиксированным количеством членов, сумму с заданной точностью и точное значение функции.
- Повторить вычисления для всех значений аргумента в заданном интервале.

### Описание программы

Программа предназначена для приближённого вычисления функции (y = arctg(x)\\) с использованием её разложения в степенной ряд. Вычисления выполняются двумя способами: с фиксированным количеством членов ряда и с заданной точностью.

В начале программы подключаются необходимые библиотеки. Библиотека `iostream` используется для вывода результатов на экран, `clocale` — для настройки локали, а `cmath` — для работы с математическими функциями, такими как `fabs()` и `atan()`.

В функции `main()` с помощью `setlocale(LC_ALL, "Russian")` устанавливаются русские языковые настройки.

Далее задаются исходные данные. Переменные `a` и `b` определяют начало и конец интервала изменения аргумента. Переменная `k` задаёт количество шагов, `n` — количество членов ряда, а `eps` — требуемую точность вычислений.

Шаг изменения аргумента вычисляется по формуле:

[ h = (b - a) / k ]

Внешний цикл `for` перебирает значения аргумента `x` от 0.1 до 1.0 включительно. Для каждого значения выполняются дальнейшие вычисления.

Сначала рассчитывается сумма ряда с фиксированным количеством членов. Для этого используются переменные `sn` и `term`. Переменная `sn` хранит накопленную сумму, а `term` содержит текущий член ряда. Перед началом вычислений сумма устанавливается равной нулю, а первый член ряда принимает значение `x`.

Внутренний цикл `for` выполняется от `j = 0` до `j = 40` включительно. На каждой итерации текущий член ряда прибавляется к сумме `sn`. После этого вычисляется следующий член ряда на основе предыдущего по формуле:

[ a{j+1} = a{j} * (-x^2) * ((2 * j + 1) / (2 * j + 3)) ]

Такой способ позволяет получать следующие члены ряда без повторного вычисления степеней числа (x).

После завершения первого цикла программа вычисляет сумму с заданной точностью. Для этого используется переменная `se`, которая изначально равна нулю. Переменная `term` снова принимает значение `x`, а счётчик `j` устанавливается в ноль.

Цикл `while` продолжает вычисления до тех пор, пока абсолютное значение текущего члена ряда не станет меньше заданной точности `eps`. Функция `fabs()` возвращает абсолютное значение числа, благодаря чему проверка корректно выполняется как для положительных, так и для отрицательных членов ряда.

Если условие цикла выполняется, текущий член добавляется к сумме `se`, после чего вычисляется следующий член ряда. Счётчик `j` увеличивается на единицу. Когда абсолютное значение очередного члена становится меньше заданной точности, цикл завершается.

Затем с помощью функции `atan(x)` из библиотеки `cmath` вычисляется точное значение арктангенса для текущего аргумента. Полученный результат сохраняется в переменной `y`.

В конце каждой итерации внешнего цикла с помощью оператора `cout` выводятся четыре значения: аргумент `x`, сумма `sn`, сумма `se` и точное значение функции `y`.

Таким образом, программа последовательно вычисляет значения арктангенса на заданном интервале, используя два способа приближённого вычисления, и позволяет сравнить полученные результаты с точным значением функции.

### Результат работы

В результате выполнения программы для каждого значения аргумента от 0.1 до 1.0 вычисляются три значения:

- `Sn` — приближённое значение арктангенса при использовании 41 члена степенного ряда.
- `Se` — приближённое значение арктангенса при заданной точности (0.0001).
- `y` — точное значение арктангенса, вычисленное с помощью стандартной функции `atan()`.

Программа выводит результаты в консоль в следующем формате:

```
X: 0.100000 Sn: ... Se: ... y: ...
X: 0.190000 Sn: ... Se: ... y: ...
...
X: 1.000000 Sn: ... Se: ... y: ...
```

Полученные значения `Sn` и `Se` должны быть близки к точному значению `y`. Это позволяет оценить точность вычислений с использованием степенного ряда.
