# Лабораторная работа №4
## Работа с одномерными массивами
### Цель:
Получение навыков обработки одномерных массивов.

### Постановка задачи.
1)  Реализовать с использованием массива двунаправленное кольцо (просмотр возможен в обе стороны, от последнего элемента можно перейти к первому).
2)  Распечатать полученный массив, начиная с К-ого элемента и до К-1 ( по кольцу влево).
3)  Добавить в кольцо первый и 3 последних элемента.
4)  Распечатать полученный массив, начиная с К-ого элемента (и до К+1  по кольцу вправо).

### Задание. Вариант 21.
Программа содержится в файле [code.cpp](code.cpp).\
Также к ней составлена блок-схема через специальное приложение drawio, содержимое которой предоставлено в файле [blocks.drawio](blocks.drawio).

### Алгоритм решения

Для решения задачи необходимо выполнить следующие действия:

- Подключить библиотеки для ввода и вывода данных, а также настройки локали.
- В основной функции `main()` установить русскую локаль с помощью `setlocale(LC_ALL, "Russian")`.
- Задать размер исходного массива (`n = 8`), переменную `k` для хранения номера начального элемента и объявить массив `arr[100]`.
- С помощью цикла `for` заполнить массив элементами, введёнными пользователем.
- Запросить у пользователя номер элемента `K`, с которого будет начинаться просмотр кольца.
- Проверить корректность введённого значения `K`. Если оно выходит за допустимые границы, завершить выполнение программы.
- Преобразовать номер элемента `K` в индекс массива, уменьшив его на единицу, поскольку индексация массива начинается с нуля.
- Организовать просмотр массива влево с помощью цикла `for`. Для перехода между элементами использовать формулу `(k - i + n) % n`, обеспечивающую циклическое перемещение от последнего элемента к первому.
- Вывести элементы массива, начиная с K-го элемента и заканчивая K-1-м по кольцу влево.
- Сохранить первый элемент исходного массива в отдельной переменной `first`.
- Добавить в конец массива первый элемент исходного массива.
- Добавить три последних элемента исходного массива в конец массива.
- Обновить размер кольца, увеличив количество элементов на четыре (`newN = n + 4`).
- Организовать просмотр изменённого массива вправо с помощью цикла `for`. Для определения текущего индекса использовать формулу `(k + i) % newN`.
- Вывести элементы изменённого массива, начиная с K-го элемента и заканчивая K+1-м по кольцу вправо.
- Завершить выполнение программы.

### Описание программы

Программа предназначена для реализации двунаправленного кольца с использованием массива. Она позволяет просматривать элементы в двух направлениях, переходить от последнего элемента к первому, а также добавлять новые элементы в кольцо.

В начале программы подключаются необходимые библиотеки. Библиотека `iostream` используется для ввода и вывода данных, а `clocale` — для настройки локали.

В функции `main()` с помощью `setlocale(LC_ALL, "Russian")` устанавливаются русские языковые настройки.

Далее объявляются основные переменные. Константа `n` задаёт количество элементов исходного массива и принимает значение 8. Переменная `k` используется для хранения номера элемента, с которого начинается просмотр кольца. Массив `arr[100]` предназначен для хранения исходных и добавленных элементов.

С помощью цикла `for` пользователь вводит восемь элементов массива. После этого программа запрашивает значение `K` — номер элемента, с которого необходимо начать просмотр.

Для проверки правильности введённого значения используется условный оператор `if`. Если значение `K` меньше 1 или больше количества элементов массива, программа выводит сообщение об ошибке и завершает работу.

Поскольку индексация массива в C++ начинается с нуля, значение `k` уменьшается на единицу:

```
k--;
```

После этого программа выполняет просмотр исходного массива влево. Для этого используется цикл `for`, который выполняется `n` раз.

На каждой итерации вычисляется индекс текущего элемента по формуле:

\\[ index = (k - i + n) \bmod n \\]

Использование операции `%` позволяет организовать циклический переход между элементами массива. Если при движении влево индекс становится меньше нуля, происходит переход к последнему элементу массива.

Полученный индекс используется для обращения к соответствующему элементу массива `arr[index]`. Все элементы выводятся на экран в порядке обхода от K-го до K-1-го.

Далее программа переходит к добавлению новых элементов в кольцо.

Сначала первый элемент исходного массива сохраняется в переменной `first`:

```
int first = arr[0];
```

Затем этот элемент добавляется в конец массива:

```
arr[n] = first;
```

После этого в массив последовательно добавляются три последних элемента исходного массива. Для этого используются следующие обращения:

- `arr[n - 3]` — третий элемент с конца;
- `arr[n - 2]` — предпоследний элемент;
- `arr[n - 1]` — последний элемент.

Добавленные элементы размещаются в позициях `n + 1`, `n + 2` и `n + 3` соответственно.

После добавления элементов определяется новый размер кольца:

[ newN = n + 4 ]

Таким образом, количество элементов увеличивается с 8 до 12.

На заключительном этапе программа выполняет просмотр изменённого массива вправо. Для этого снова используется цикл `for`, который выполняется `newN` раз.

Индекс текущего элемента определяется по формуле:

[ index = (k + i) mod new N ]

В отличие от предыдущего обхода, здесь индекс увеличивается на каждой итерации. Когда достигается последний элемент массива, операция `%` обеспечивает переход обратно к первому элементу.

Полученные элементы выводятся на экран в порядке обхода, начиная с K-го элемента.

Таким образом, программа реализует двунаправленное кольцо на основе массива, выполняет просмотр элементов влево и вправо, а также добавляет в кольцо первый и три последних элемента исходного массива.

### Результат работы

В результате выполнения программы пользователь получает возможность ввести восемь элементов массива и указать номер начального элемента `K`.

Сначала программа выводит исходный массив, начиная с K-го элемента и заканчивая K-1-м при движении влево.

Затем в кольцо добавляются четыре элемента:

- Первый элемент исходного массива.
- Третий элемент с конца исходного массива.
- Предпоследний элемент исходного массива.
- Последний элемент исходного массива.

После добавления размер кольца увеличивается с 8 до 12 элементов. Программа выводит изменённый массив, начиная с K-го элемента и заканчивая K+1-м при движении вправо.

Пример ввода:

```
Enter 8 array elements:
1 2 3 4 5 6 7 8
Enter K (from 1 to 8): 3
```

Пример вывода:

```
Array moving left: 3 2 1 8 7 6 5 4

Modified array moving right: 3 4 5 6 7 8 1 1 6 7 8 2
```

В ходе выполнения задания была реализована структура двунаправленного кольца с использованием массива. Были изучены принципы циклического перемещения по массиву влево и вправо с помощью операции остатка от деления `%`.

Также была реализована возможность добавления новых элементов в кольцо без нарушения порядка исходных элементов.

В результате программа успешно выполняет обход массива в обоих направлениях, обеспечивает переход между последним и первым элементами и позволяет просматривать изменённое кольцо после добавления новых элементов.
