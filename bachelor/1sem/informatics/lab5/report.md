# Лабораторная работа №5
## Функции и массивы
### Цель:
Организовать обработку массивов с использованием функций, научиться передавать массивы как параметры функций.

### Постановка задачи.
Используя функции, решить указанную в варианте задачу. Массив должен передаваться в функцию как параметр.

### Задание. Вариант 21.
Программа содержится в файле [code.cpp](code.cpp).\
Также к ней составлена блок-схема через специальное приложение drawio, содержимое которой предоставлено в файле [blocks.drawio](blocks.drawio).

### Алгоритм решения

Для решения задачи необходимо выполнить следующие действия:

- Подключить библиотеки для ввода и вывода данных, а также настройки локали.
- В основной функции `main()` установить русскую локаль с помощью `setlocale(LC_ALL, "Russian")`.
- Задать размеры двумерного массива с помощью констант `ROWS = 3` и `COLS = 4`.
- Объявить и заполнить двумерный массив целочисленными значениями.
- Создать отдельную функцию `findMaxRepeated()`, принимающую двумерный массив в качестве параметра.
- В функции `findMaxRepeated()` объявить переменную `maxRepeated` для хранения максимального повторяющегося элемента.
- С помощью двух вложенных циклов `for` организовать перебор всех элементов двумерного массива.
- Для каждого текущего элемента объявить и обнулить переменную `count`, предназначенную для подсчёта количества его повторений.
- С помощью ещё двух вложенных циклов `for` выполнить сравнение текущего элемента со всеми элементами двумерного массива.
- Если значения элементов совпадают, увеличить счётчик `count` на единицу.
- После завершения подсчёта проверить, встречается ли текущий элемент более одного раза.
- Если элемент повторяется, сравнить его значение с текущим максимальным повторяющимся элементом.
- Если значение текущего элемента больше, обновить переменную `maxRepeated`.
- После завершения перебора всех элементов вернуть значение `maxRepeated` из функции.
- В функции `main()` вызвать функцию `findMaxRepeated()`, передав ей исходный двумерный массив.
- Сохранить возвращённое значение в переменной `result`.
- Вывести исходный массив на экран.
- Проверить результат выполнения функции. Если повторяющиеся элементы найдены, вывести максимальный из них. В противном случае вывести сообщение об отсутствии повторяющихся элементов.
- Завершить выполнение программы.

### Описание программы

Программа предназначена для поиска максимального из повторяющихся элементов двумерного массива с использованием отдельных функций.

В начале программы подключаются необходимые библиотеки. Библиотека `iostream` используется для ввода и вывода данных, а `clocale` — для настройки локали.

Далее с помощью директивы `using namespace std` подключается стандартное пространство имён.

Для определения размеров двумерного массива используются две константы:

```
const int ROWS = 3;
const int COLS = 4;
```

Константа `ROWS` определяет количество строк массива, а `COLS` — количество столбцов.

Для поиска максимального повторяющегося элемента создаётся отдельная функция `findMaxRepeated()`, которая принимает двумерный массив в качестве параметра:

```
int findMaxRepeated(int arr[ROWS][COLS])
```

Внутри функции объявляется переменная `maxRepeated`, предназначенная для хранения максимального найденного повторяющегося элемента. Изначально ей присваивается значение 0.

Для перебора всех элементов массива используются два вложенных цикла `for`. Переменные `i` и `j` определяют текущую строку и столбец массива.

Для каждого элемента выполняется подсчёт количества его повторений. С этой целью объявляется переменная `count`, начальное значение которой равно нулю.

Затем запускаются ещё два вложенных цикла `for`, с помощью которых текущий элемент сравнивается со всеми элементами двумерного массива.

Если значения совпадают, выполняется увеличение счётчика:

```
if (arr[i][j] == arr[k][l]) {
    count++;
}
```

Таким образом, переменная `count` содержит количество вхождений текущего элемента в массив, включая его собственное вхождение.

После завершения внутреннего перебора программа проверяет, встречается ли текущий элемент более одного раза:

```
if (count > 1)
```

Если условие выполняется, элемент является повторяющимся.

Далее его значение сравнивается с текущим максимальным повторяющимся элементом. Если значение больше, переменная `maxRepeated` обновляется:

```
if (count > 1 && (maxRepeated == 0 || arr[i][j] > maxRepeated)) {
    maxRepeated = arr[i][j];
}
```

После завершения перебора всех элементов функция возвращает найденное значение:

```
return maxRepeated;
```

В основной функции `main()` устанавливается русская локаль с помощью `setlocale(LC_ALL, "Russian")`.

Затем объявляется и заполняется двумерный массив размером 3 × 4:

```
int arr[ROWS][COLS] = {
    { 5, 12, 7, 3 },
    { 12, 8, 15, 7 },
    { 4, 9, 15, 2 }
};
```

Для отображения исходного массива используется два вложенных цикла `for`, которые последовательно выводят элементы каждой строки.

После этого вызывается функция `findMaxRepeated()`, которой передаётся исходный массив:

```
int result = findMaxRepeated(arr);
```

Возвращённое функцией значение сохраняется в переменной `result`.

На заключительном этапе с помощью условного оператора `if` проверяется полученный результат. Если значение отлично от нуля, программа выводит максимальный повторяющийся элемент. В противном случае выводится сообщение об отсутствии повторяющихся элементов.

Таким образом, программа выполняет поиск максимального повторяющегося элемента двумерного массива с использованием отдельной функции, которой массив передаётся в качестве параметра.

### Результат работы

В результате выполнения программы на экран выводится исходный двумерный массив, после чего определяется и отображается максимальный элемент, который встречается в массиве более одного раза.

В качестве исходных данных используется следующий массив:

```
5    12    7    3
12   8     15   7
4    9     15   2
```

В данном массиве повторяются следующие элементы:

- `12` — встречается два раза.
- `7` — встречается два раза.
- `15` — встречается два раза.

Максимальным из повторяющихся элементов является число `15`.

Пример вывода:

```
Исходный массив:
5    12    7    3
12   8     15   7
4    9     15   2

Максимальный из повторяющихся элементов: 15
```
