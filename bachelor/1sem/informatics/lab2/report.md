# Лабораторная работа №2
## Использование основных операторов языка Си
### Цель:
Получение навыков в выборе и использовании операторов Си++; знакомство с итерационными процессами.

### Постановка задачи.
Используя оператор цикла, найти сумму элементов, указанных в конкретном варианте. Результат напечатать, снабдив соответствующим заголовком.

### Задание. Вариант 21.
Программа содержится в файле [code.cpp](code.cpp).\
Также к ней составлена блок-схема через специальное приложение drawio, содержимое которой предоставлено в файле [blocks.drawio](blocks.drawio).

### Алгоритм решения

Для решения задачи необходимо выполнить следующие действия:

- Подключить библиотеки для ввода и вывода данных, работы с математическими функциями и настройки локали.
- Создать функцию factorial(int n) для вычисления факториала числа (n).
- Инициализировать переменную s, которая хранит сумму ряда, нулевым значением.
- С помощью цикла for перебрать значения (n) от 1 до 13 включительно.
- Для каждого значения вычислить очередной член ряда по формуле (a_n=\ln(n!)/n^2).
- Добавить вычисленный член к общей сумме.
- Вывести итоговое значение суммы на экран.

### Описание программы

Для вычисления факториала используется отдельная функция factorial(int n). Она начинает вычисление с единицы и последовательно умножает результат на целые числа от 1 до (n). Полученное значение возвращается в основную программу.

В функции main() переменная s используется для накопления суммы. Цикл for выполняется 13 раз, последовательно принимая значения от 1 до 13.

На каждой итерации функция factorial(i) вычисляет факториал текущего числа. Затем функция log() из библиотеки <cmath> вычисляет натуральный логарифм факториала, а выражение i * i определяет квадрат номера члена ряда. Результат деления сохраняется в переменной a и прибавляется к сумме s.

После завершения цикла программа выводит итоговую сумму с помощью cout.

Для хранения промежуточных результатов используется тип long double, позволяющий выполнять вычисления с повышенной точностью по сравнению с типом float.
