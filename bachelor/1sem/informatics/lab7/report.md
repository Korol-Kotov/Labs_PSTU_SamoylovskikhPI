### Описание программы

Программа предназначена для выполнения двух задач: подсчёта отрицательных элементов в массиве целых чисел и подсчёта слов в строке, у которых первая и последняя буквы совпадают.

В начале программы подключаются необходимые библиотеки:

```
#include <iostream>
#include <clocale>
```

Библиотека `iostream` используется для ввода и вывода данных, а `clocale` — для настройки локали.

Далее с помощью директивы `using namespace std` подключается стандартное пространство имён.

Первая перегруженная функция

Для подсчёта отрицательных элементов массива используется функция:

```
int count(int a[], int n)
```

Данная функция принимает целочисленный массив `a` и его размер `n`.

В начале функции объявляется переменная:

```
int result = 0;
```

Она предназначена для хранения количества отрицательных элементов. Изначально её значение равно нулю.

Для проверки элементов массива используется цикл `for`:

```
for (int i = 0; i < n; i++) {
    if (a[i] < 0) {
        result++;
    }
}
```

Цикл последовательно перебирает все элементы массива. Для каждого элемента проверяется условие `a[i] < 0`.

Если условие выполняется, значение переменной `result` увеличивается на единицу с помощью оператора `++`.

После завершения цикла функция возвращает найденное количество отрицательных элементов:

```
return result;
```

Вторая перегруженная функция

Для подсчёта слов, начинающихся и заканчивающихся на одну и ту же букву, используется вторая функция:

```
int count(char s[])
```

Она принимает символьный массив `s`, содержащий исходную строку.

Несмотря на одинаковое название, эта функция отличается от первой типом принимаемого параметра. Благодаря этому в программе реализуется перегрузка функций.

В начале функции объявляется переменная:

```
int result = 0;
```

Она используется для подсчёта слов, удовлетворяющих заданному условию.

Также объявляется переменная:

```
int i = 0;
```

Она отвечает за перемещение по символам исходной строки.

Для обработки строки используется цикл:

```
while (s[i] != '.' && s[i] != '\0')
```

Цикл выполняется до тех пор, пока не встретится точка или символ конца строки.

Внутри цикла сначала пропускаются пробелы между словами:

```
while (s[i] == ' ') {
    i++;
}
```

Это необходимо для перехода к началу следующего слова.

Далее сохраняется начальная позиция текущего слова:

```
int start = i;
```

С помощью следующего цикла определяется конец слова:

```
while (s[i] != ' ' && s[i] != '.' && s[i] != '\0') {
    i++;
}
```

Переменная `i` увеличивается до тех пор, пока программа не встретит пробел, точку или конец строки.

После определения границ слова вычисляется его длина:

```
int len = i - start;
```

Для проверки текущего слова используется условие:

```
if (len > 0) {
    if (s[start] == s[start + len - 1]) {
        result++;
    }
}
```

Сначала проверяется, что слово не пустое.

Затем сравниваются первый и последний символы слова. Первый символ находится по индексу `start`, а последний — по индексу `start + len - 1`.

Если символы совпадают, значение переменной `result` увеличивается на единицу.

После завершения обработки всей строки функция возвращает количество подходящих слов:

```
return result;
```

Основная функция `main()`

В основной функции программы сначала устанавливается русская локаль:

```
setlocale(LC_ALL, "Russian");
```

Затем объявляется переменная для хранения размера массива:

```
int n;
```

Размер массива вводится пользователем:

```
cout << "Enter array size: ";
cin >> n;
```

После этого объявляется целочисленный массив:

```
int a[256];
```

С помощью цикла `for` пользователь вводит все элементы массива:

```
for (int i = 0; i < n; i++) {
    cin >> a[i];
}
```

После ввода массива вызывается первая перегруженная функция:

```
cout << "Number of negative elements: " << count(a, n) << endl;
```

В функцию передаются массив `a` и его размер `n`. Полученное значение выводится на экран.

Далее очищается входной буфер:

```
cin.ignore(1000, '\n');
```

Это необходимо для корректного ввода строки после чтения чисел.

Затем объявляется символьный массив:

```
char s[256];
```

В него записывается исходная строка с помощью функции:

```
cin.getline(s, 256);
```

После ввода строки вызывается вторая перегруженная функция:

```
cout << "Number of matching words: " << count(s) << endl;
```

В функцию передаётся символьный массив `s`, а результат её работы выводится на экран.

Таким образом, программа вызывает две перегруженные функции с одинаковым именем, каждая из которых выполняет отдельную задачу в зависимости от типа переданных аргументов.

### Результат работы

В результате выполнения программы на экран выводится количество отрицательных элементов массива и количество слов, у которых первая и последняя буквы совпадают.

В качестве исходных данных используется следующий массив:

```
-5 3 -2 7 -1 4
```

Рассмотрим проверку его элементов:

- `-5` — отрицательное число.
- `3` — положительное число.
- `-2` — отрицательное число.
- `7` — положительное число.
- `-1` — отрицательное число.
- `4` — положительное число.

Таким образом, в массиве содержится 3 отрицательных элемента.

В качестве исходной строки используется:

```
level hello radar world.
```

Рассмотрим проверку отдельных слов:

- `level` — первая и последняя буквы совпадают (`l` и `l`).
- `hello` — первая и последняя буквы не совпадают (`h` и `o`).
- `radar` — первая и последняя буквы совпадают (`r` и `r`).
- `world` — первая и последняя буквы не совпадают (`w` и `d`).

Таким образом, условию соответствуют 2 слова.

Пример вывода программы:

```
Enter array size: 6
Enter array elements: -5 3 -2 7 -1 4
Number of negative elements: 3
Enter a string: level hello radar world.
Number of matching words: 2
```
